📁 Carpeta: 02_Data_Understanding

Esta carpeta corresponde a la segunda fase del proceso CRISP-DM: Comprensión de los Datos (Data Understanding).  
Su propósito es obtener, explorar y comprender los datos disponibles que se utilizarán en el análisis o modelado.  
Durante esta etapa se identifican las fuentes de información, se evalúa la calidad de los datos y se extraen las primeras conclusiones sobre su contenido y estructura.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

📂 bruto

Subcarpeta destinada a almacenar el dataset original o CSV bruto obtenido directamente desde la base de datos o fuente de información inicial.  
Este archivo representa los datos en su estado original, antes de cualquier limpieza, transformación o selección de variables.  
Sirve como punto de partida para todas las tareas de exploración y verificación en esta fase.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

📓 02_Data_Understanding.ipynb

Notebook de Jupyter que contiene el análisis exploratorio inicial de los datos.  
Aquí se realiza la carga del dataset bruto, se examinan sus características principales (columnas, tipos de datos, valores nulos, distribuciones, etc.) y se identifican posibles problemas de calidad o inconsistencias.  
El notebook también documenta las primeras observaciones, patrones relevantes y relaciones entre variables que servirán de base para la siguiente fase (Data Preparation).

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

📌 Resumen: 
La carpeta 02_Data_Understanding tiene como finalidad asegurar una comprensión profunda del conjunto de datos disponible.  
Permite verificar la pertinencia, completitud y coherencia de la información, estableciendo los cimientos técnicos y analíticos sobre los cuales se construirá el modelo predictivo o descriptivo.
