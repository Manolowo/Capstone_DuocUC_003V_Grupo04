📁 Carpeta: 01_Business_Understanding

Esta carpeta corresponde a la primera fase del proceso CRISP-DM: Comprensión del Negocio.  
Su propósito es identificar los objetivos del proyecto desde la perspectiva organizacional, entender las necesidades del negocio y definir los criterios que determinarán el éxito del análisis o modelo a desarrollar.  
Aquí se establecen las bases conceptuales sobre las cuales se construirá todo el proceso analítico.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

🗒️ 01_01_objetivos.md

Documento que describe los objetivos principales del proyecto, tanto estratégicos como analíticos.  
Permite entender qué busca lograr la organización mediante el uso de datos y qué metas guiarán el desarrollo posterior del modelo o análisis.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

🗒️ 01_02_preguntas_negocio.md

Archivo que recoge las preguntas clave del negocio que se espera responder con el análisis de datos.  
Estas preguntas orientan las futuras exploraciones, modelamientos y evaluaciones, asegurando que el proyecto mantenga una conexión directa con las necesidades reales de la organización.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

🗒️ 01_03_criterios_exito.md

Documento que define los criterios de éxito que permitirán evaluar el impacto y la efectividad del proyecto.  
Establece las condiciones que deben cumplirse para considerar que los resultados satisfacen las expectativas del negocio y entregan valor tangible.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

📓 01_Business_Understanding.ipynb

Notebook de Jupyter que integra toda la información y conclusiones obtenidas en esta fase.  
Funciona como un informe unificado, donde se documentan los objetivos, las preguntas de negocio, los criterios de éxito y las observaciones generales.  
Sirve como punto de referencia consolidado para pasar a las fases siguientes del proceso CRISP-DM.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

🧾 query_creacion_vista.txt

Archivo que contiene el query SQL utilizado para crear una vista en la base de datos, la cual genera el conjunto de datos necesario para el análisis.  
Su propósito es preparar la extracción de datos desde las fuentes originales y generar el CSV base que se utilizará en las fases de comprensión y preparación de datos.  
Este query asegura que la información relevante quede correctamente estructurada y disponible para el modelado posterior.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

📌 Resumen:
La carpeta 01_Business_Understanding constituye la base del proyecto analítico.  
Su objetivo es conectar los desafíos del negocio con los objetivos técnicos, garantizando que cada decisión de modelado responda a una necesidad concreta y medible.
